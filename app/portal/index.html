            How this works

            Each card is one page that stays, with the names that may be the same. Click a name to see its notes first. Merge moves the notes into the page that stays and keeps the other name as an alias, so that spelling links there from now on. Not the same stops the suggestion.

            Each night the decision model checks new pairs, and the note writer LLM decides the pairs it is not sure about. 80% sure or more: merged. 10% or less: marked not the same. Only the pairs between come to you. Names that differ only by spaces or dashes merge by themselves. Every automatic merge can be undone below.

            No possible duplicates. All decided.

            Decided automatically

            Merges by the model and by the same-name rule, and pairs the model marked not the same. Undo a wrong merge: the other page comes back and the pair is not suggested again.

              What gets backed up

              • Every note and setup file in the vault, except what .gitignore excludes. .env files are never committed.
